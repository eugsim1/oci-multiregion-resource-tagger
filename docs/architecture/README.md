# Architecture diagram

`oci-multiregion-resource-tagger.drawio` is the editable source. The SVG export is embedded in the repository README.

The diagram uses official shapes copied from Oracle's OCI Architecture Diagram Toolkit for Draw.io:

- OCI User
- OCI IAM
- OCI Compartment
- OCI Virtual Machine
- OCI Block Storage

Region boundaries and flow connectors use standard Draw.io containers styled to match the OCI visual language.

Toolkit source: <https://docs.oracle.com/en-us/iaas/Content/General/Reference/graphicsfordiagrams.htm>

The icons remain Oracle artwork and are used here only to describe the OCI services operated by this independent project.
